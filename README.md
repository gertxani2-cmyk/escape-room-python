# 🚪 Escape Room - Python Analytics Project

This is a text-based, interactive adventure game built in Python 3 as a collaborative team project during our bootcamp. The player wakes up in a locked house and must explore rooms, examine environments, collect hidden items (keys, a flashlight, batteries, and a hammer), and input codes to escape before a 450-second countdown timer expires.

## 👥 Team Roles & Contributions
* **Research Team (Gert & Ana):** Conducted topic-specific research, mapped out structural game components, debugged logical bottlenecks, handled functional error validation, and ensured best practices across Python data structures.
* **Dev Team (Andre):** Responsible for the core game development, constructing backend functions (`play_room`, `examine_item`, `check_timer`), setting up room/item dictionaries, and implementing layout assets.

## 📁 Repository Contents
* `main.ipynb` - The primary entry point where the game loop is executed.
* `game.py` - The core engine containing room datasets, logic conditions, and countdown functions.
* `Project _ Escape Room - Secret Chamber (2).pdf` - The final Google Slides presentation documenting our strategic workflow and logic map.
* `Escape Room Images (1).rar` - Consolidated archive folder containing visual background assets rendered during gameplay.

## 🎮 How to Play
1. Open the repository files in Google Colab or Jupyter Notebook.
2. Run the code blocks inside `main.ipynb` to initiate the game.
3. Interact with the interface using numeric choices: press `1` to explore, `2` to examine, or `3` to check the remaining time.
